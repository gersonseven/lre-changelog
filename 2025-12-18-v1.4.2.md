Introducing **occurrence rescheduling**, **Meta Box support**, and **locale-aware date formatting**.

## Added

### Occurrence Rescheduling
- Move individual occurrences to different dates without changing the recurrence pattern
- New "Reschedule this occurrence" mini toggle in the Occurrence Overrides section
- Date picker to select the new date for the occurrence
- Visual feedback showing the original and new dates
- Rescheduled dates appear correctly in query loops and dynamic tags
- Works alongside field overrides (can reschedule AND change fields in one action)

### Reschedule Notes
- Add explanatory notes when rescheduling occurrences
- Optional "Note" textarea in the reschedule section
- Notes automatically display in calendar offcanvas panel
- Notes automatically display in calendar list view
- New shortcode: `[lre_reschedule_note]`
- New Bricks dynamic tag: `{lre_reschedule_note}`

### Meta Box Plugin Support
- Full integration with Meta Box custom fields plugin
- Auto-detection of Meta Box fields via `rwmb_get_registry()`
- Field retrieval using `rwmb_get_value()` function
- Supports all standard Meta Box field types

### Locale-Aware Date Formatting
- All date displays now respect WordPress site language and timezone settings
- Month names translated: "December" → "Dezember" (German), "Diciembre" (Spanish), etc.
- Weekday names translated: "Monday" → "Montag", "Lunes", etc.
- New German-style date format option: `j. F Y` (e.g., "26. Dezember 2025")
- `Config::format_date()` and `Config::format_timestamp()` helper methods

## Fixed
- Dual toggle vertical alignment in metabox
- Metabox field spacing consistency
- Override field dropdowns now use locale-aware date formatting

## Changed
- Renamed "Field Overrides" section to "Occurrence Overrides"
- Start date field is now excluded from the Override Fields selector
- Calculator applies reschedule logic automatically
- All display formatting now uses `wp_date()` for proper localization
