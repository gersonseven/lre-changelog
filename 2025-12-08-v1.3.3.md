New **Pickr color picker**, **auto-contrast text colors**, and improved offcanvas theming.

## Added
- **Pickr Color Picker**: Bundled Pickr library (v1.9.1, MIT licensed) replaces WordPress wp-color-picker for improved popup behavior and consistent styling
- **Auto-Contrast Text Colors**: Offcanvas panel and category color previews now automatically calculate contrasting text colors for optimal readability
- **Offcanvas Color Customization**: Dark mode support with theme-aware color options
- **Theme-Aware Defaults**: Offcanvas color reset button dynamically updates its default value based on the selected theme preset

## Changed
- Offcanvas Panel Colors simplified to single Background color input (text color auto-calculated)
- Offcanvas styling moved to Theme & Styling section for better organization

## Fixed
- JetEngine field detection now uses wp_options approach with proper fallbacks
- Calendar time display for daily recurrence and custom date occurrences
- Manage Exclusions modal dates not loading correctly
- Manage Exclusions modal saving issues
- Unsaved changes notice showing incorrectly
- Pickr popup positioning for category colors (was appearing ~400px offset)
