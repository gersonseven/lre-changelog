Full **ACPT integration** with auto-detection, **Flatpickr time picker**, and numerous fixes.

## Added

### ACPT Integration
- Full support for Advanced Custom Post Types (ACPT) field plugin
- Auto-detection of ACPT meta box names — no manual configuration needed
- Uses ACPT's API to find which box contains each field
- Fallback pattern matching on existing meta keys if API unavailable
- Box name included in field data for accurate field retrieval
- `Config::get_date_meta_key()` — Returns the actual database meta key for queries

### Flatpickr Time Picker
- Time override fields now use flatpickr library for better UX
- Displays in 12-hour format (e.g., "2:30 PM") for user-friendly selection
- Stores in 24-hour format (HH:MM) for database compatibility
- 5-minute increment for quick selection
- Consistent styling with existing date picker implementation

## Fixed
- **ACPT Field Detection**: Fixed `belongsTo` parameter from `'post_type'` to `'customPostType'`
- **ACPT Field Retrieval**: Fixed function call with correct array signature and `'return' => 'raw'` parameter
- **ACPT Calendar Display**: Fixed WP_Query using wrong meta_key for ACPT fields
- **ACPT Type Mapping**: Comprehensive type normalization covering all ACPT field types
- **Time Field Derivation**: Now handles hyphenated field names (e.g., `event-start-date` → `event-start-time`)
- **Calendar Dots Click Handler**: Fixed clicking on event dots opening wrong event
- **Override Values in Offcanvas**: Fixed overridden field values not displaying in calendar offcanvas
- **Dashicons Not Displaying**: Fixed dashicons in metabox buttons not rendering
- **Stale Override Fields**: Override fields from deactivated plugins are now auto-removed

## Improved
- Override field inputs are now disabled until an occurrence date is selected
- Shows informative notice prompting user to select a date first
- Fields enable automatically when date is chosen

## Changed
- ACPT field parser now uses JSON deep conversion for reliable object handling
- Excluded additional complex ACPT field types: List, Clone
- Improved ACPT detection using multiple indicators
- Override field inputs now match 40px height for consistent styling

## Removed
- ACPT Meta Box Name Setting (auto-detection replaces manual configuration)
