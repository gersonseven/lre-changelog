Override any field value for specific occurrences — perfect for events where one date has a different time, location, or speaker.

## Per-Occurrence Customization

- Select any occurrence date and override its field values
- Changes only affect that specific date
- Original recurrence pattern stays intact

## Dynamic Data Support

Access overridden values in your templates:
- Dynamic tag: `{lre_field:field_name}`
- Shortcode: `[lre_field name="field_name"]`

## URL Parameters

Single event pages now support occurrence-specific URLs:
- Format: `?lre_date=YYYY-MM-DD`
- Query loops automatically include the date parameter
- Templates display the correct override values

## Field Detection

Automatically detects fields from:
- ACF
- JetEngine
- Meta Box
- Pods
