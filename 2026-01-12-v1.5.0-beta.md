🚀 A massive update bringing **Elementor integration**, **advanced Bricks elements**, **AJAX filtering**, and much more!

## Added

### Bricks Builder Enhancements

- **Pagination Element** — Paginate query loop results with full styling controls
  - Posts per page setting in query controls
  - Page numbers, previous/next navigation
  - Full typography, color, and spacing controls

- **Event Occurrences Element** — Display upcoming dates for a single event
  - Two display modes: List and Mini Calendar
  - List mode: Vertical/horizontal layouts, separators, full styling
  - Mini Calendar: Month grid, navigation arrows, dot indicators
  - Link dates to occurrence URLs with `?occurrence=` parameter
  - Exclude Current Occurrence toggle

- **Filter Elements for Bricks** — Complete filtering system for query loops
  - Date Filter Element — Preset ranges (Today, This Week, etc.) or custom dates
  - Date Range Filter Element — Flatpickr-powered calendar picker
  - Taxonomy Filter Element — Filter by category, tag, or custom taxonomy
  - Search Filter Element — Text search across events
  - Event Type Filter Element — Filter recurring vs one-off events
  - Reset Filters Element — Clear all active filters
  - All elements have comprehensive styling controls
  - Target query loop selection via dropdown

- **Query Loop Enhancements**
  - Taxonomy filter with include/exclude mode
  - Date range presets or custom range selection
  - Include/exclude specific event IDs
  - Offset to skip first N results
  - Meta query for custom field filtering

- **New Dynamic Tags**
  - `{lre_occurrences}` — Comma-separated list of all occurrences
  - `{lre_occurrences:N}` — First N occurrences
  - `{lre_occurrences_count}` — Total count of upcoming occurrences

### Elementor Integration

- **Recurring Events Loop Widget** — Complete Elementor integration
  - Dedicated widget in "Lista Recurring Events" category
  - Default Card Template built-in (no template creation required)
  - Support for Elementor Section templates (works with free Elementor)
  - Responsive column controls with gap settings
  - Three pagination styles: Page Numbers, Load More, and Infinite Scroll

- **Date Filter Widget** — Filter events by date range
  - Preset date ranges: Today, Tomorrow, This Week, Next Week, This Month, Next Month, This Year
  - Custom date picker with From/To date inputs
  - Multiple display styles: Buttons, Pills, Dropdown

- **Taxonomy Filter Widget** — Filter events by category/tag
  - Supports all taxonomies registered for event post types
  - Multiple display styles: Buttons, Pills, Dropdown, Checkboxes, Radio Buttons
  - Single or multiple selection modes

- **Elementor Dynamic Tags**
  - Occurrence Date, Time, End Date, Duration
  - Next Occurrence with relative date option
  - Post Title, URL, Featured Image, Excerpt, Terms

### Calendar & Event Display

- **Add to Calendar Button** — Visitors can save events to personal calendars
  - Supports Google Calendar, Apple Calendar, Microsoft 365, iCal download, Yahoo, and Outlook.com
  - Master toggle in Settings
  - New `[lre_add_to_calendar]` shortcode
  - Custom-built component with no external dependencies

- **Default Calendar Visibility Settings** — Per-post-type defaults

### Core Features

- **Multi-Post Type Support** — Configure multiple post types simultaneously
- **AJAX Filtering** — Smooth, no-refresh filtering with browser history support
- **Enhanced Shortcodes** — New display options and filter shortcodes
- **JavaScript Translation Support** — Full i18n for admin metabox
- **Enhanced Debugging** — Debug tab, URL parameters, public API methods

- Page no longer scrolls to top when closing offcanvas
- Post URLs in query loops return correct event URL
- Timezone consistency with `wp_timezone()`
- Multiple override rows saving correctly

- Flatpickr locale errors resolved
- AJAX container detection improved
- Elementor pagination for consecutive clicks
- Load More button state after AJAX
- Infinite scroll trigger detection
