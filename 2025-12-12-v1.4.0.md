Introducing the **Add-on Extensibility System** — hooks for third-party add-ons to extend functionality.

## Added

### Add-on Extensibility System
- `lre_init` — Fire after core initialization with calculator instance
- `lre_settings_tabs_nav` — Add custom settings page tabs
- `lre_settings_tab_content` — Render custom settings tab content
- `lre_metabox_tabs_nav` — Add custom metabox tabs
- `lre_metabox_tabs_panels` — Render custom metabox tab panels
- `lre_after_save_recurrence` — Fire after event recurrence settings saved

### Developer Notes
- Add-ons can now extend Lista Recurring Events without modifying core code
- Designed to support future ticketing integrations (FluentCart, SureCart, WooCommerce)
- Add-ons should check `LRE_VERSION` constant for compatibility
