We're excited to launch **Lista Recurring Events** — a powerful WordPress plugin for managing recurring events with page builder integration.

## Recurrence Patterns

Create events that repeat on any schedule:
- **Daily** — Every day or every X days
- **Weekly** — Select specific days of the week
- **Monthly** — By date or by weekday (e.g., "2nd Tuesday")
- **Yearly** — Annual events on specific dates

## Bricks Builder Integration

Full dynamic data support for Bricks Builder:
- Custom query loop type for recurring events
- Dynamic tags for occurrence dates and times
- Automatic date parameter handling in permalinks

## Shortcodes

Display events anywhere with shortcodes:
- `[lre_next_date]` — Show the next occurrence
- `[lre_occurrences]` — List all upcoming dates
- `[lre_field]` — Display custom field values

## Field Source Support

Works with your favorite custom field plugins:
- ACF (Advanced Custom Fields)
- JetEngine
- Meta Box
- Pods
- Standard WordPress meta
