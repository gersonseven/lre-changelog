Major feature release with **Occurrence Overrides** — set different field values for specific dates.

## Added

### Occurrence Overrides
- Set different field values for specific occurrence dates
- Field detection for ACF, JetEngine, Meta Box, and Pods
- Overrides settings tab to configure which fields can be overridden
- Overrides tab in metabox to add/edit per-occurrence values

### Dynamic Data
- Dynamic data tags for override fields: `{lre_field:field_name}`
- Shortcode for override fields: `[lre_field name="field_name"]`
- Override context automatically set during query loops

### URL Parameters
- URL parameter support for single event pages: `?lre_date=YYYY-MM-DD`
- Permalinks in query loops automatically include occurrence date
- Single event templates display correct override values based on URL

### Other
- Copy-to-clipboard for all dynamic tags and shortcodes in settings

## Fixed
- Plugin update checker now uses official FluentCart SDK
- Default Occurrences setting properly applies to Bricks, Elementor, and metabox preview
