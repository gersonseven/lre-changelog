Major release introducing **FullCalendar integration**, **REST API**, **theme presets**, and **ACPT support**.

## Added

### Calendar Integration
- **FullCalendar Integration**: Beautiful, interactive calendar with `[lre_calendar]` shortcode
- **REST API Endpoints**: `/wp-json/lre/v1/events` for calendar data and `/wp-json/lre/v1/event/{id}` for event details
- **Offcanvas Panel**: Animated side panel showing event details on click
- **Theme Presets**: Three built-in themes (Default, Minimal, Dark)
- **Custom Color Overrides**: Per-calendar and per-event color customization
- **Per-Event Colors**: Color picker in metabox for individual event styling
- **Multi-Day Event Support**: Events spanning multiple days render correctly across calendar grid
- **Intelligent Prefetching**: Smooth month navigation with preloaded event data
- **Smart Dot Indicators**: Days with multiple events show colored dots
- **Custom Tooltips**: Hover over dots to see event titles
- **Mobile Day View**: Optimized list layout for touch devices
- **Custom Navigation Arrows**: Upload custom SVG icons for calendar navigation

### Core Features
- **Dual Toggle System**: Separate "Enable recurring event" and "Display event in calendar" toggles in the metabox
- **Calendar Settings Tab**: Configure default view, theme, behavior, and display options
- **ACPT Support**: Advanced Custom Post Types field source integration
- **Display Fields Configuration**: Choose which fields appear in offcanvas panel
- **Shortcode Attributes**: Inline customization (theme, colors, view, height, etc.)
- **Custom Admin Menu Icon**: 360° rotation symbol replaces generic dashicon
- **Settings Link**: Quick access from Plugins list page

## Changed
- Field retriever now supports 6 sources: ACF, ACPT, JetEngine, Pods, Meta Box, Standard WP
- Calendar Display tab controlled by dedicated toggle instead of recurring toggle
- Improved REST API error handling with proper date validation
- Settings MENU_SLUG changed from private to public for plugin action links

## Security
- Added SVG sanitization for uploaded custom icons (removes scripts, event handlers, and dangerous elements)
- Improved output escaping for image URLs in shortcodes (now uses `esc_url()`)
- Verified all AJAX handlers have nonce verification and capability checks

## Fixed
- Toggle visual state not updating on first click
- Tab content displaying incorrectly when multiple tabs enabled
- Tab panel visibility now controlled entirely by CSS `.active` class
